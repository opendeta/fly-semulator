How it works

Light position → per-eye drive on the fly's visual sensory neurons → through the measured connectome → descending neurons → motor neurons → steering and speed. Synapse signs come from predicted neurotransmitter identity (GABA/glutamate = inhibitory). Nothing between the eyes and the muscles is hand-wired.

Architecture

This page is static, served by GitHub Pages. The brain cannot run here — GitHub Pages has no compute. So the simulation runs on a separate machine and this page just connects to it: docs/backend.json tells the page where the live backend is.

Honest limits

  • LIF is a strong simplification: real neurons have unknown dynamics, delays and neuromodulation that the connectome does not contain.
  • The body is a stylized 3D model, not NeuroMechFly/MuJoCo. An innate phototaxis term sits alongside the brain-derived steering (both are knobs above).
  • The live backend is a temporary tunnel — when it sleeps, the video stops but this page stays.
